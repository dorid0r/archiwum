# Komponent newslettera

## Opis
Komponent newslettera posiada dwa tryby kolorystyczne. Po dodaniu klasy "--dark". Tło zmienia się na ciemne, a teksty na białe.
Generowany kod html został zoptymalizowany, nie wyświetla się tam ukryta grafika.
