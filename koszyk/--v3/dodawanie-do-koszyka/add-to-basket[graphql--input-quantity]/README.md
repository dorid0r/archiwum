# Dodawanie do koszyka 

### Wywołanie funkcjonalności

```js
  //wyłowanie funkcji dodania do koszyka dla hotspotów
  app_shop.fn.ProductBuyHotspots = new ProductBuy('.hotspot');
  app_shop.fn.ProductBuyHotspots.init();
  
  
  //wyłowanie funkcji dodania do koszyka dla searcha
  app_shop.fn.ProductBuySearch = new ProductBuy('#search');
  app_shop.fn.ProductBuySearch.init();
```
